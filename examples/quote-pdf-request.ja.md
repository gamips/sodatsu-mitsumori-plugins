# 見積書を作ってPDFを取得する依頼例

対応するAIクライアントで育つ見積に接続したあと、次のように依頼できます。宛名と品目は架空のサンプルです。

> 架空の「サンプル株式会社」宛てに、「サンプル品目（架空）」1式、単価10,000円、外税10%の見積書を1件作成し、PDFファイルを取得してください。共有URLは不要です。

実行すると見積書が保存されます。Freeでは、作成できる通算5件にこの1件も含まれます。
